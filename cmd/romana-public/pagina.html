Română

Ce face

verifica_greseli

Găsește greșelile sigure, cele care nu depind de context: ș și ț cu sedilă, grafia veche cu „î” în interiorul cuvintelor și „sînt”, „vroiam”, spațiile dinaintea semnelor de punctuație și spațiile duble.

Întoarce textul cu aceste greșeli corectate și lista lor, fiecare cu rândul, cuvintele din jur, regula și sursa ei.

cauta_regula

Caută în cele 854 de reguli ale skillului romana, după ID (RO-TIP-027) sau după cuvinte („a face sens”).

Dă fiecare regulă cu nivelul ei, exemplul greșit și cel corect, explicația și sursa.

Serverul nu judecă sensul, acordul, coerența sau stilul, iar dicționarul dexonline nu e pe el. Cele mai bune rezultate le dă împreună cu skillul romana.

Limite

Text verificat 200.000 de caractere pe apel

Aproximativ 110 pagini standard. Un text mai lung îl trimiți pe bucăți.

Răspuns 200 de greșeli descrise

Textul corectat le cuprinde pe toate, iar răspunsul spune câte erau în total.

Pe zi, de la aceeași adresă IP 2.000 de apeluri

Și cel mult 600 de reguli diferite. Ziua se socotește după ora UTC. Toate regulile sunt și pe GitHub.

Căutarea de reguli 10 reguli pe răspuns

Interogarea are cel mult 200 de caractere.

Ritm 10 cereri pe secundă

De la aceeași adresă.

English

What it does

At most 200,000 characters per call and 2,000 calls per day from the same IP address. All limits

verifica_greseli

Finds the errors in Romanian text that do not depend on context: ș and ț written with a cedilla, the old spelling with „î” inside words and „sînt”, „vroiam”, spaces before punctuation marks and double spaces.

Returns the text with these errors corrected and a list of them, each with its line, the surrounding words, the rule and its source.

cauta_regula

Searches the 854 rules of the romana skill, by ID (RO-TIP-027) or by words („a face sens”).

Gives each rule with its level, the wrong and the correct example, the explanation and the source.

The server does not judge meaning, agreement, coherence or style, and the dexonline dictionary is not on it. It works best together with the romana skill.

Limits

Checked text 200,000 characters per call

About 110 standard pages. Send a longer text in parts.

Response 200 itemized errors

The corrected text includes all of them, and the response gives the total.

Per day, from the same IP address 2,000 calls

And at most 600 distinct rules. The day follows UTC. All the rules are also on GitHub.

Rule search 10 rules per response

A query has at most 200 characters.

Rate 10 requests per second

From the same address.

How to add it

claude.ai

From the Claude directory or, in the web or desktop app: Customize → Connectors → Add custom connector, with the server address and no authentication.

ChatGPT

Install the romana-plugin.zip archive (Plugins → Add → Upload plugin archive); it already contains the server.

Claude Code

claude mcp add --transport http romana-public https://mcp.doitmagic.ro/mcp

Codex

The plugin installed from doITmagic/romana already includes it. Manually, in ~/.codex/config.toml:

[mcp_servers.romana-public]
url = "https://mcp.doitmagic.ro/mcp"

For Cursor, VS Code and GitHub Copilot, see the README.

Privacy

Checked texts stay in memory only while the response is computed and are not kept. Usage statistics record the tool, the client app, the country, cauta_regula queries and the IDs of the rules found, not the texts. Details: privacy and terms.
