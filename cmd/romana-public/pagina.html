romana: server MCP pentru texte în limba română

Serverul dă asistentului tău de AI două unelte. verifica_greseli găsește în textele românești greșelile care sunt greșeli oriunde: ș și ț cu sedilă, grafia veche cu „î” în interiorul cuvintelor și „sînt”, „vroiam”, spațiile dinaintea semnelor de punctuație și spațiile duble, fiecare cu regula și sursa ei. cauta_regula caută în cele 854 de reguli ale skillului romana, după ID (RO-TIP-027) sau după cuvinte („a face sens”).

Serverul nu judecă sensul, acordul, coerența sau stilul, iar dicționarul dexonline nu e pe el. E gratuit, doar de citire și nu cere cont. Cele mai bune rezultate le dă împreună cu skillul romana.

Adresa serverului

https://mcp.doitmagic.ro/mcp

Streamable HTTP, fără autentificare.

Cum îl adaugi

claude.ai

Din directorul Claude sau, în aplicația web ori pe desktop: Customize → Connectors → Add custom connector, cu adresa de mai sus și fără autentificare.

Claude Code

claude mcp add --transport http romana-public https://mcp.doitmagic.ro/mcp

Codex

Pluginul instalat din doITmagic/romana îl include deja. Manual, în ~/.codex/config.toml:

[mcp_servers.romana-public]
url = "https://mcp.doitmagic.ro/mcp"

ChatGPT

Instalează arhiva romana-plugin.zip (Plugins → Add → Upload plugin archive); ea conține deja serverul.

Pentru Cursor, VS Code și GitHub Copilot, vezi README.

Confidențialitate

Textele verificate rămân în memorie doar cât se calculează răspunsul și nu se păstrează. Statisticile de folosire înregistrează unealta, aplicația clientă, țara, interogările către cauta_regula și ID-urile regulilor găsite, nu textele. Detaliile sunt la confidențialitate și condiții.

English

romana is a free, read-only MCP server for Romanian text, with two tools: verifica_greseli finds the errors that are wrong anywhere (ș and ț with a cedilla, the old spelling with „î” inside words, „sînt”, „vroiam”, spaces before punctuation, double spaces), and cauta_regula searches the 854 rules of the romana skill by ID or by words. It does not judge meaning, agreement, coherence or style, and it keeps no texts.

Add this address as a remote MCP server (Streamable HTTP, no authentication) in claude.ai (Claude directory or Customize → Connectors → Add custom connector), Claude Code, Codex, ChatGPT, Cursor or VS Code:

https://mcp.doitmagic.ro/mcp
